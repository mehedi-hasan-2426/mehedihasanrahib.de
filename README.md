# mehedihasanrahib.de

Personal portfolio of Mehedi Hasan Rahib, live at https://mehedihasanrahib.de.

## Stack

- **Framework:** Astro 7 with TypeScript, static output
- **UI:** React 19 islands, Motion for the one animated tile
- **Styling:** Tailwind CSS 4 plus a small hand-written stylesheet
- **Content:** MDX project pages in `src/content/projects`
- **API:** Hono routes under `/api`, prerendered at build time (public GitHub data, no secrets)
- **Hosting:** Vercel through `@astrojs/vercel`, sitemap via `@astrojs/sitemap`
- **Quality:** ESLint, Prettier, Playwright, strict CSP with hashes generated by Astro

Astro 7 needs Node 22.23.4 or newer; CI and Vercel use Node 24.

## Run locally

```powershell
npm ci
npm run dev
```

Open http://127.0.0.1:4321. Production build: `npm run build`, then `npm run preview` (http://127.0.0.1:4173).

Behind a TLS-inspecting proxy the build-time GitHub fetch may fail; set `$env:NODE_USE_SYSTEM_CA="1"` so Node trusts the Windows certificate store. Without data the tile shows a plain fallback text.

## Automation

- CI runs on every push and pull request, and every Monday by cron, so a broken dependency shows up even without commits.
- [Renovate](renovate.json) replaces Dependabot version updates once the
  [GitHub App](https://github.com/apps/renovate) is installed for this repository.
  Routine updates are grouped by package manager before 06:00 Monday, Europe/Berlin,
  with a three-day release-age delay. Vulnerability PRs bypass that delay and schedule.
- All updates need manual review and passing checks. Major updates additionally need
  Dependency Dashboard approval. Keep Dependabot alerts and existing security scans enabled.

## Checks

```powershell
npm run lint
npm run build
npx playwright install chromium
npm test
```

If the browser download is blocked, use an installed browser: `$env:PW_CHANNEL="msedge"; npm test`.

Keyboard checks cover the home page, project pages and 404 page. Pressing Tab first
reveals "Skip to content"; Enter moves focus into the main content without adding
the main container to the normal tab order.
